# Cone Player releases

This repository only hosts Cone Player's in-app update feed (`appcast.xml`) and its signed, notarized DMGs, published with GitHub Pages at <https://jeffevertse.github.io/cone-player-releases/>.

Cone Player itself, its source code and its issue tracker are at <https://github.com/jeffevertse/cone-player>.

The feed and DMGs are generated by `scripts/release.sh --publish` in that repository. Every update is signed with an EdDSA key that the app checks before installing.
